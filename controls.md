Gamepad :

* Dpad up / right : next weapon
* Dpad down / left : previous weapon
* Analog stick : look / turn
* Start : pause / main menu
* Y button : forward
* A button : backward
* X button : strafe left
* B button : strafe right
* Left trigger : jump
* Right trigger : attack / fire

Mouse / keyboard :

* Movement : look / turn
* Left button : attack / fire
* Right button : jump
* Wheel mouse up : next weapon
* Wheel mouse down : previous weapon
* Side button : once held strafe is enabled
* UP arrow : forward
* DOWN arrow : backward
* LEFT arrow : strafe left
* RIGHT arrow : strafe right

Notes :

* Original keyboard shorcuts from the PC version remain the same
* Always run is set to ON
* MadCatz gamepad : Z/C buttons = left/right trigger (default settings)
* Mouse look is not inverted
